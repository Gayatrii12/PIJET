# PICT's International Journal on Engineering & Technology - PIJET

Official website for PIJET - PICT

## Requirements
- Install Node.js and npm.

## Start the site
1. Run `npm install`.
2. Run `npm start`.
3. Open `http://localhost:3000` in a browser.

## Make a build
- Run `npm run build`. The build goes to the `build` folder.

## Add a new issue
1. Put the PDF files in `public/papers/`.
2. Add the paper list in `src/data/paperMaps.js`.
3. Show the new issue in `src/pages/Archive.js`.

## Contact
- Send an email to `pijet@pict.edu`.
